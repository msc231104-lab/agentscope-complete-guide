## Beginner Level (Foundation Phase)

These build your core understanding and practical basics.

### 1. Basic Concepts

You learn:

- what agents are
- how models work
- memory/context
- tools
- message flow

This is pure foundation.

### 2. Building Blocks

You learn:

- how agents are assembled
- RAG
- orchestration
- tool capabilities
- memory systems

This is beginner-to-intermediate system design.

### 3. Tutorial

You learn:

- how complete agents are built
- practical workflows
- real implementations

This is applied beginner/intermediate learning.

## Intermediate Level

### 4. Observe & Evaluate

You learn:

- debugging
- tracing
- observability
- evaluations
- performance measurement

This is where engineering maturity begins.

### 5. Tune Agent

You learn:

- model selection
- prompt optimization
- RL concepts
- multi-agent optimization

This is intermediate-to-advanced optimization work.

## Advanced Level

### 6. Out-of-box Agents

You analyze:

- production-grade architectures
- complex orchestration
- specialized agents
- advanced workflows

This is advanced because understanding these deeply requires strong fundamentals.

### 7. Deploy & Serve

You learn:

- scaling
- deployment
- serving infrastructure
- monitoring
- concurrency
- production systems

This is advanced/production engineering.
